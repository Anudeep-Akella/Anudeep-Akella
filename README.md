A production-ready AI chatbot leveraging the Groq API for ultra-fast inference with Meta's Llama models. Showcases modern LLM integration patterns, prompt engineering, and real-time conversational AI—proving that speed doesn't mean sacrificing intelligence.

**Tech**: Qiskit, Quantum Computing, Python, Research Paper
